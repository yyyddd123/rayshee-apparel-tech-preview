# Rayshee Apparel Tech Website Preview

## View and edit from another computer

1. Sign in to GitHub.
2. Open: https://codespaces.new/yyyddd123/rayshee-apparel-tech-preview
3. Select **Create codespace on main**.
4. Wait for the private preview to open.
5. The preview address is private and requires your GitHub login.

The cloud environment runs `python3 -m http.server 4173` automatically and forwards the preview securely.

## Public read-only preview

https://yyyddd123.github.io/rayshee-apparel-tech-preview/

## Main files

- `index.html`: homepage
- `assets/css/styles-clean.css`: complete visual system
- `assets/js/site.js`: navigation, modal, forms and cart behavior
- `assets/images/editorial/`: temporary editorial images
- Other folders: individual pages and blog posts

This is a local/static front-end preview. Real email, payment and WordPress administration require server-side integration.
